# 🏥 Medicio - Healthcare Website

A modern and responsive **Healthcare Website** built using **HTML and CSS**, designed to provide medical services information, doctor details, and appointment booking interface.

---

## 🚀 Features

- 🏥 Clean and modern healthcare UI  
- 📱 Fully responsive design  
- 🎯 Smooth animations using AOS library  
- 🩺 Medical services section  
- 👨‍⚕️ Doctors profile section  
- 📅 Appointment booking form  
- 📍 Google Maps integration  
- 📞 Contact section with form  
- 🔝 Scroll-to-top button  

---

## 🛠️ Technologies Used

- 🌐 HTML5  
- 🎨 CSS3  
- ⭐ Font Awesome Icons  
- 🎬 AOS (Animate On Scroll) Library
